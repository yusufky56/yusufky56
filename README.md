### Hi, I'm Yusuf

Computer engineer. I build web and desktop applications and work on deep learning for medical imaging and NLP. Most of my code is in Python, C#, C++, Java and TypeScript. Right now I'm working on a mobile app.

#### Research projects
Code and results behind my published papers. Each one uses leakage-free data splits and reports confidence intervals.

| Project | What it does | Result |
|---|---|---|
| [Retinal OCT classification](https://github.com/yusufky56/oct-retinal-disease-classification) | ConvNeXt-V2 and RETFound + LoRA on a patient-level split of OCT2017 | 98.8% accuracy |
| [Sign language recognition](https://github.com/yusufky56/sign-language-recognition) | Benchmark of 10 CNN and Vision Transformer models with Grad-CAM | 99.25% accuracy |
| [AQI forecasting](https://github.com/yusufky56/aqi-forecasting) | Next-day air quality forecasting with LSTM, GRU and Transformer | R² 0.899 |
| [Fake news detection](https://github.com/yusufky56/fake-news-detection-bert) | BERT fine-tuning on ISOT after removing 6,252 duplicate articles | 99.98% accuracy |
